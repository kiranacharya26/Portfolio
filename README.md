# My React App

This project is a simple React application styled with Tailwind CSS. It features a responsive layout with a header and footer.

## Project Structure

```
my-react-app
├── public
│   ├── index.html
│   └── favicon.ico
├── src
│   ├── components
│   │   ├── Footer.js
│   │   └── Header.js
│   ├── App.js
│   ├── index.css
│   └── index.js
├── package.json
├── tailwind.config.js
├── postcss.config.js
└── README.md
```

## Features

- **Header**: Contains main text on the left and four social connection links on the right, styled with a white background and appropriate padding.
- **Footer**: Displays "All rights reserved" text centered with the current year, also styled with padding and full width.

## Getting Started

To get started with this project, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd my-react-app
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm start
   ```
